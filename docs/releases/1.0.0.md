## DomainRecon 1.0.0

Première version publique. DomainRecon audite vos propres domaines et en tire une note de sécurité, la
liste des points à corriger et des conseils de correction concrets. Application de bureau pour Windows et
Linux, en français et en anglais, entièrement locale.

### Nouveautés

- **84 modules** répartis en 8 familles : Web, TLS, E-mail, DNS et sous-domaines, Réseau, Identité,
  Réputation, Fuites de données.
- **Note de A à F** et score sur 100, calculés sur les seuls critères mesurés, avec la couverture du barème.
- **Comprendre et corriger** pour chaque constat : explication, étapes, extrait de configuration à copier et
  lien vers la documentation officielle, en français et en anglais.
- **Trois profils** : rapide, complet, personnalisé. Les modules actifs et sensibles exigent l'autorisation
  de tester la cible.
- **Comparaison** de deux scans, **lot** de domaines, **historique** et **timeline**.
- **Surveillance** planifiée avec alertes : notification de bureau, Discord, Slack, Teams, webhook JSON,
  e-mail SMTP. Une tâche système prend le relais quand l'application est fermée.
- **Exports** PDF, HTML, Markdown, CSV, JSON, SARIF et JUnit.
- **Ligne de commande** complète (`scan`, `batch`, `history`, `export`, `modules`, `import`, `monitor`),
  utilisable en intégration continue avec `--fail-under`.
- **Visite guidée** au premier lancement, aide et glossaire intégrés.
- **Désinstallation complète** depuis les Réglages, avec sauvegarde proposée.

### Livrables

| Système | Fichier |
|---|---|
| Windows 10 / 11 (64 bits), installeur | `DomainRecon-1.0.0-setup.exe` |
| Windows 10 / 11 (64 bits), portable un seul fichier | `DomainRecon-1.0.0-portable.exe` |
| Windows 10 / 11 (64 bits), portable zip | `DomainRecon-1.0.0-portable-win64.zip` |
| Ubuntu 22.04+ / Debian 12+ (amd64) | `domainrecon_1.0.0_amd64.deb` |

Chaque livrable embarque Python, l'interface et Chromium : rien d'autre à installer. Guide complet :
[installation](https://github.com/w4ll-i/DomainRecon/blob/main/docs/installation.md).

### Vérifier les fichiers

Comparez l'empreinte de chaque fichier à `SHA256SUMS`, joint à cette release :

```powershell
Get-FileHash .\DomainRecon-1.0.0-setup.exe -Algorithm SHA256
```

```bash
sha256sum -c --ignore-missing SHA256SUMS
```

Chaque fichier a aussi une attestation de provenance :

```bash
gh attestation verify DomainRecon-1.0.0-setup.exe --repo w4ll-i/DomainRecon
```

### Limites connues

- **Avertissement SmartScreen** : les exécutables Windows ne sont pas signés. Windows affiche « Windows a
  protégé votre ordinateur » : après avoir vérifié l'empreinte, cliquez sur **Informations
  complémentaires**, puis sur **Exécuter quand même**.
- Le portable en un seul fichier démarre plus lentement : il se décompresse à chaque lancement dans un
  dossier temporaire.
- Linux : paquet `.deb` pour amd64 seulement. Pas de version macOS.
- Le module Nuclei n'est lancé que si le binaire Nuclei est installé sur la machine (non fourni).
- En mode navigateur, un onglet mis en veille par le navigateur compte comme fermé : le serveur peut
  s'arrêter. Relancez DomainRecon, puis rechargez la page.
